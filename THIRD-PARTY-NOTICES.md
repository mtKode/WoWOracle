## Not included: downloaded on your PC

Neither this repository nor the release zip contains game data or game art. The app downloads it to
`%LOCALAPPDATA%\WowCompanion` when it runs, and caches it so each file is fetched once:

| What | From | Notes |
|---|---|---|
| Game tables (items, spells, talents, maps), icons, map tiles and talent art | [wago.tools](https://wago.tools) | Files from the game client; © Blizzard Entertainment. |
| Item sources, drop chances, NPCs, quests | [CMaNGOS classic-db](https://github.com/cmangos/classic-db) | GPL-2.0 database; game content © Blizzard Entertainment. |
| File id → file name list | [wowdev/wow-listfile](https://github.com/wowdev/wow-listfile) | Community list. |
| Talent layout for Icy Veins / Wowhead links (only when you use those links) | [Icy Veins](https://www.icy-veins.com) | Fetched at most once a week per class. |

## Fonts

The Friz Quadrata font (Blizzard's licensed font) is not included unless the zip was built with `publish.ps1 -IncludeFont`; keep that for private copies. Otherwise the app uses it only if it finds it on your PC.

The leather backdrop is original, generated by `tools/make-background.py`. The app icon is original.
